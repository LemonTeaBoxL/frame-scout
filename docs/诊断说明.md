# 诊断记录说明

先开启诊断模式，再重新检测目标视频。旧检测无法回溯逐帧依据。

- 默认位置：`%LOCALAPPDATA%/FrameScout/diagnostics`。
- `latest.json` 指向最新会话；历史会话保留在同级目录，界面可跨会话查询。
- `index.json`：视频完整路径、诊断ID、开始结束时间、状态与记录目录。
- `frame-metrics.csv`：每帧差异、变化面积、暗像素比例、亮度、黑屏及边界门槛结果。
- `frame-times.csv`：实际帧时间戳；界面帧号从1开始，FrameIndex从0开始。
- `thresholds.json`：该次分析实际使用的全部阈值。
- `decisions.jsonl`：短暂返回、单侧边界、片头残帧等候选及合并、尾部、黑屏过滤依据。
- `analysis.json`：最终发现、规则名称与范围说明。
- `ffmpeg.log`：该视频分析的解码输出。
- `events-*.jsonl`：操作、播放、布局、项目和字幕/API进度等程序事件。

询问某一帧时，按视频路径与诊断ID确认具体哪次检测，再读取对应指标和候选记录。默认查询最近完成的记录，较新的取消或失败不会覆盖已完成依据。

日志会脱敏已配置的API密钥，不附视频、剧本、字幕原文件和API配置；导出包仍包含本地路径等调试信息，由用户决定如何保存与分享。
