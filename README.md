# 视频巡检 · Frame Scout

<img src="图标/视频巡检.png" width="72" alt="视频巡检图标">

轻量 Windows 视频与字幕巡检工具。检测夹帧、黑屏，并结合剧本校对字幕中的专有名词。

**当前版本：v1.5** · [下载便携版](https://github.com/LemonTeaBoxL/frame-scout/releases/latest)

## 功能

- 视频或文件夹拖放导入、并行检测、0–100 灵敏度。
- 夹帧默认最多持续 4 帧；支持从尾黑前最后有效画面倒数跳过指定尾部帧数。
- 黑屏默认检查前后各 15 帧，中间黑屏可选。
- 点击异常定位视频，逐帧查看、前后帧对照、审核状态与异常视频导航。
- 右键定位资源管理器；悬停渐显前后各15帧，移出渐隐，支持原尺寸PNG保存。
- 可选诊断模式，按视频和帧号查看逐帧指标、触发规则与过滤依据，支持历史查询和导出。
- 视频三栏、字幕四栏布局，可调宽、独立悬浮及保存项目。
- 自然名称、时长、分辨率、总帧数、状态等排序。
- Shift＋滚轮横移；中键拖动或轻点后自动滚动，Esc 退出。
- SRT 关联同名视频；剧本路径拖放、专有名词提取与七种格式名词表导入。
- OpenAI 兼容接口、模型列表读取、分组并发校对、进度和日志。
- 采纳、撤销和另存字幕；重置状态时保留素材和关联。

## 运行

Windows 10/11 x64，使用系统 .NET Framework 4.8。下载 Releases 中的完整便携包，解压后运行 `视频巡检.exe`，保留 `引擎` 文件夹。升级时先关闭旧版。

视频分析在本机完成。字幕校对按用户配置将剧本与字幕文本发送到对应 API，可能产生服务商费用。API 密钥使用当前 Windows 用户加密保存，不写入项目和报告。

## 从源码构建

无需 Python 或第三方 GUI 框架。

1. 安装 .NET Framework 4.8。
2. 运行仓库根目录的 `构建.cmd`。
3. 将 Windows x64 的 `ffmpeg.exe` 放到 `引擎` 目录，再运行生成的 `视频巡检.exe`。

构建脚本会先编译构建工具和图标生成器，再编译 WPF 程序。详细操作见 [使用说明](docs/使用说明.txt)。

## 检查与边界

本版通过 251 项程序内控件与功能检查，另验证了诊断跨进程读取。真实鼠标拖动的外部端到端复测因画面采集超时未完成，跨不同缩放比例的物理显示器未实测。字幕流程使用本机模拟 API 验证，真实服务商效果取决于用户配置和模型。

夹帧为疑点提示，正常切镜或闪光也可能被报告，请结合前后画面审核。详见 [验证说明](docs/验证说明.txt) 和 [诊断说明](docs/诊断说明.md)。
